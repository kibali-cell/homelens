# HomeLens

**Learn the fundamentals of machine learning by building one realistic project end to end.**

HomeLens predicts the median house value of a California district and flags "premium" districts (top 25% by price). It is one dataset and one locked test set, carried through 11 steps that cover the core of classical machine learning with scikit-learn.

## Why this exists

Most ML tutorials teach techniques in isolation. HomeLens connects them: every concept appears when the project needs it, every number is regenerated by code, and the test set stays locked until the final step. Negative results (PCA hurting, ensembles not winning) are kept on purpose.

## Results (locked test set, opened once)

| Task | Model | Result |
| --- | --- | --- |
| Regression | HistGradientBoosting + geo-cluster features | RMSE about $41.8k (95% CI $40.0k to $43.6k), MAE about $27.5k, R² 0.87 |
| Baseline | Predict the mean | RMSE about $114k |
| Premium classifier | HistGradientBoosting | Precision 0.89, recall 0.84, F1 0.86, AUC 0.97 |

Data: 1990 California census districts, prices capped at $500k. This is a learning project, not a valuation tool.

## The 11 steps

| Step | Topic | File |
| --- | --- | --- |
| 1 | Framing, baselines, bias and variance | `steps/step01_framing.py` |
| 2 | Exploration and data quirks | `steps/step02_eda.py` |
| 3 | Leak-free pipeline, custom transformer, CV, randomized search | `steps/step03_pipeline_models.py` |
| 4 | Classification metrics and thresholds | `steps/step04_classification.py` |
| 5 | Training internals: gradient descent, regularisation, early stopping | `steps/step05_training_models.py` |
| 6 | Support vector machines | `steps/step06_svm.py` |
| 7 | Decision trees | `steps/step07_trees.py` |
| 8 | Ensembles and the model bake-off | `steps/step08_ensembles.py` |
| 9 | PCA, kernel PCA, t-SNE | `steps/step09_dimensionality.py` |
| 10 | Clustering, mixtures, anomaly detection | `steps/step10_unsupervised.py` |
| 11 | Final model, confidence interval, error analysis, artifacts | `steps/step11_final_model.py` |

Each step is a plain `.py` file split into `# %% block` cells. Run one with `python tools/run_step.py steps/step06_svm.py`; each block's output is saved to `reports/outputs/<step>/`.

## Quick start

```bash
git clone https://github.com/kibali-cell/homelens.git
cd homelens
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .
python -m homelens.predict      # score three example districts with the shipped models
python -m pytest -q tests       # run the tests
bash run_all.sh                 # regenerate every number and figure (about 10-12 min, 2 cores)
```

## Project layout

```
src/homelens/   config, data, features (ClusterSimilarity), tasks, predict
steps/          the 11 runnable steps
tests/          pytest suite for the pipeline
tools/          step runner (and optional PDF builder)
artifacts/      trained models and model_card.json
reports/        figures and recorded outputs
data/housing.csv
```

## What you will be able to do

- Build a leak-free scikit-learn pipeline with a custom transformer
- Pick metrics and thresholds for imbalanced classification
- Explain bias, variance, regularisation, and early stopping with evidence
- Tune SVMs, trees, forests and boosting and say why one won
- Know when PCA and ensembles help, and when they do not
- Report a final score with a confidence interval, not just a number
